## 📖 关于本项目

此仓库是一个**纯数据归档仓库**（Data Repository），专门用于集中存放每日拉取的高清必应（Bing）壁纸。

本项目的照片均来自 **[必应主页](https://cn.bing.com/)**，版权均归属原作者和提供方所有。

## 📂 存储结构

壁纸按照严谨的时间线与图片类型分别存放于以下目录中：

```text
📦 Bing-Wallpapers
 ┣ 📂 Basics     (原始 UHD 超高清画质图)
 ┃  ┣ 📂 2024
 ┃  ┣ 📂 2025
 ┃  ┗ 📂 2026
 ┃     ┣ 📂 01
 ┃     ┗ 📂 02  (格式：YYYYMMDD_图片标题.jpg)
 ┃
 ┗ 📂 Add Exif   (写入了原图版权与相关描述 EXIF 信息的图)
    ┣ 📂 2024
    ┣ 📂 ...
```

## ⚙️ 更新机制

这里的图片由自动化工作流程序每日定时静默抓取并推送更新至此专属仓库，无需人工上传与干预。
