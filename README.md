## 📂 存储结构

```text
Bing-Wallpapers/
├── Basics/          原始 UHD 超高清壁纸
│   └── YYYY/MM/     按年月归档 (YYYYMMDD_标题.jpg)
└── Add Exif/        注入版权与描述 EXIF 信息的版本
    └── YYYY/MM/
```
